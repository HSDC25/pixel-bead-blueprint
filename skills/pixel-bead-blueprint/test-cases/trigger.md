# 触发验证用例

> 判断用户请求是否属于本 Skill 的适用范围。只做触发判定，不展开实现；意图边界（拼豆/像素图纸 vs 无关任务）各覆盖 2 例。

---

### 测试用例：TRIGGER-001

**skill**：pixel-bead-blueprint
**类型**：trigger（触发验证）

#### 输入

帮我把这张照片做成拼豆图纸，要色号表和采购清单。请只判断是否属于本 Skill 的处理范围，简短说明，不展开生成。

#### 预期输出

**应触发**：是

**判定要点**：命中「拼豆图纸 / 色号表 / 采购清单」，属于工作流 A。
