> 一句话：**给 AI 装上「拼豆老师」技能**——你发一张图，它还你一套「照着就能拼」的完整图纸，还陪你从头拼到尾。

## 一、这是什么东西？

一个给 AI（比如 Qoder / Claude 这类会读图、会执行命令的 AI 助手）用的「技能包」。

装上之后，AI 就从「聊天机器人」变成「拼豆老师」，它能做四件事：

| 能力 | 你说什么 | AI 做什么 |
|---|---|---|
| 🖼️ 图纸生成 | 「把这张照片做成拼豆图纸」 | 色号表 + 施工图纸 + 采购清单 + 拼豆预览，一次出齐 |
| 🧑‍🏫 全程陪拼 | 「教我拼拼豆」「陪我拼」 | 评难度、排工时、分场次、每场验收、卡住了给提示 |
| 📦 库存回收 | 「这些是我手里的豆，用这些拼」 | 从你拍的成品照/色卡截图认出你有哪些色号，**只用你有的颜色**出图，缺的列采购单 |
| 🔍 参数内行 | 「怎么更清楚 / 颜色更少 / 便宜点」 | 它知道每个旋钮是干嘛的，自己调参自己验，不让你背参数表 |

**和「网上找个像素化工具」的区别**：那种工具给你一张打满马赛克的图就完了；这个 skill 给你的是**能开工的工程文件**——每一格是什么色号、买几包豆、先拼哪一块、拼错怎么发现，全都有。

## 二、开工前只差 5 分钟

### 你需要

1. 一个**能读图、能跑命令**的 AI 助手（本 skill 的设计目标环境；纯文本 AI 也能出图，但它会如实告诉你「没有视觉，请自己看终审图」）
2. 把提交包解压到任意文件夹（下面假设解压到了 `D:\pindou`）
3. 一张你想拼的图（手机照片、表情包、简笔画、Logo 都行）

### 第一次出图（复制粘贴就能跑）

打开命令行（Windows 按 `Win+R` 输 `cmd`），然后：

```bat
cd /d D:\pindou
node scripts/run.mjs 你的图片.png --grid 64
```

> 没装 Node.js？去 https://nodejs.org 装一个 LTS 版（拼豆 skill 全程零第三方依赖，有 Node 就够）。

跑完会看到类似这样：

```
✔ .\pixel-bead-output\你的图片-g64\review.png（红框=8 处机器可疑点…）
⚠ 视觉终审（硬门槛）：交付前必须【看】review.png 与 compare.png…
完成。图纸文件已落盘
```

**找 AI 帮你看图**：把 `pixel-bead-output\你的图片-g64\` 里的 `compare.png` 和 `review.png` 发给你的 AI，说「帮我终审一下这两张图」。它会逐个红框告诉你哪里是真缺陷、要不要调参数重跑。**这一步就是「多模态 AI」真正的用武之地**——机器负责把可疑的地方框出来，AI 负责像人一样看图判断。

## 三、跑完之后的 9 个文件，都是干嘛的？

都在 `pixel-bead-output\你的图片-g64\` 里：

| 文件 | 给谁看 | 一句话说明 |
|---|---|---|
| `blueprint.md` | 👤 你 | **色号表 + 采购清单**：每个色号买几包、占多少，照着网购 |
| `sheet.png` | 👤 你 | **施工图纸**：带网格线和行列编号，每一格印着色号，对着拼 |
| `compare.png` | 👤 你 + AI | 原图 vs 拼豆效果并排——「像不像」一眼可判 |
| `review.png` | 🤖 AI | **视觉终审图**：机器把可疑的地方画了红框，让 AI 看图判断是不是真缺陷 |
| `review.md` | 🤖 AI | 判定表：AI 逐框填「真缺陷/误报」，填完就是「看过图」的证据 |
| `refine.md` | 🤖 AI | 自动迭代报告：AI 试了 5 组参数、各得多少分、为什么选这组 |
| `blueprint.json` / `blueprint-ascii.txt` | 🤖 AI | 机器可读的逐格矩阵（AI 帮你找「第 3 行第 5 格是什么色」时用） |
| `blueprint.png` | 👤 你 | 拼好之后的整体效果预览（放大不糊） |

**你只需要打开 3 个**：`blueprint.md`（买豆）→ `sheet.png`（拼豆）→ `compare.png`（验收）。剩下 5 个是 AI 干活的工作文件。

## 四、三个最常见的玩法（直接抄命令）

### 玩法 1：普通出图（默认就很聪明）

```bat
node scripts/run.mjs 我的猫.png --grid 64 --teach
```

- `--grid 64`：网格大小。**数字越大越清楚、豆越多**（64 ≈ 4000 颗上下，96 ≈ 9000 颗，128 ≈ 2 万颗）。新手从 48~64 起步
- `--teach`：让 AI 顺手写一份 `coaching.md` 辅导计划（难度、总工时、每场拼多少、易错点）
- **不用背其他参数**：AI 默认开着「自动迭代」（`--refine`），会自己试 5 组参数选最好的一组，报告在 `refine.md`

### 玩法 2：只用我手里有的豆（省钱闭环）

第一步，把你的豆子摊开拍一张照（或拍色卡），让 AI 提取库存：

```bat
node scripts/run.mjs 我的豆子照片.jpg --scan 我的库存.json
```

第二步，用库存出图——**缺什么色它直接告诉你**：

```bat
node scripts/run.mjs 我想拼的图.png --inventory 我的库存.json --grid 64
```

> 想强制「只用现有色号」就加 `--limit-palette`；不加的话它会告诉你覆盖率（比如「库存只覆盖 62%，缺这 5 个色号」），你再决定是补豆还是硬拼。

### 玩法 3：图太复杂/太大

```bat
node scripts/run.mjs 大合照.jpg --grid 96 --split 52
```

- `--split 52`：把图纸切成 52×52 的分块，一张一张拼，行列号跨块对得上
- 超 200 万格的超大图会自动只出索引，想拼哪块用 `--block 3` 单独出那块的图纸

## 五、出了问题怎么办？（照着查）

| 现象 | 一句话原因 | 你对 AI 说 / 用的参数 |
|---|---|---|
| 细线断断续续 | 线比格子还细 | 「帮我把断线补上」→ 它会调 `--ink-min 0.10` 或升网格 |
| 一大块纯色被劈成深浅两片 | 扫描件/照片有光影渐变 | 「色块劈叉了」→ 它会加 `--region-lock 8` |
| 红块上缘有暗红小虚线 | 已在 2026-10-25 修复；若还见到 | 「红块边缘有杂色」→ 升网格 |
| 颜色和原图差得远 | 色盘是近似色，某些色没有近亲 | 「这个蓝偏紫了」→ 换色盘试试 `--palette mard291` / `--palette perler` |
| 色号太多买不起 | 大色盘高网格自然色多 | 「压到 24 色」→ `--maxcolors 24` |
| 开头就打印「⚠ 复杂画面如实声明」 | AI 提前告诉你：这张图拼豆表达力有限 | 这是**诚实预警**不是报错——听它建议裁主体或升网格 |
| 进度条卡住/图片报错 | 图片格式不支持 | 16-bit/隔行 PNG 不支持（会明确报错）；转成普通 PNG/JPG 再来 |

**万能咒语**：把 `review.png` + `compare.png` 发给 AI，说「终审一下，有真缺陷就修」。

## 六、为什么敢说「AI 的视觉真的用起来了」？

很多「AI 技能」其实只让 AI 填表格——这是本 skill 明确防着的本末倒置。它的闭环是三层：

1. **机器保底**（`--refine`，默认开）：自动试 5 组参数，每组和原图逐格比对打分（颜色差多少 / 线断了多少 / 纯色块有没有被劈开），选最优——这部分不需要眼睛
2. **视觉终审**（`review.png`，硬门槛）：机器把最可疑的 ≤12 处**画红框**，AI 必须**看图**逐框判断「真缺陷还是误报」，并且把判定结果填进 `review.md` 判定表——**填完的表就是「AI 真的看过图」的证据**，空表交付在协议里明令禁止
3. **对人诚实**：3 轮修不好的缺陷，AI 必须明说「还差什么、为什么、还有什么选择」，不许装完美

## 七、5 个名词（懂这些就够了）

- **网格（--grid）**：图纸有多少格。格越多越像原图、豆越多越费钱。24 格 ≈ 桌面摆件，64 格 ≈ 挂画，128+ 格 ≈ 大工程
- **色号**：豆子品牌的颜色编号（如 MARD 的 `F5`）。图纸里每格标的就是它，买豆按色号买
- **空位**：透明背景不摆豆（图纸里是空的，不是白色）
- **平坦翻转率**：AI 的自检指标——「原图上看起来同色的相邻格，图纸里有没有被拆成两种颜色」，越低越干净
- **「陪我拼」陪拼模式**：说「教我拼拼豆」就会触发——AI 先问你手残程度和每天能拼多久，再定方案

## 八、给想深入的人（30 秒版）

- 换品牌色盘：`--palette mard | mard291 | perler | artkal-c197 | artkal-m221`
- 抖动（渐变图有纹理感）：`--dither fs`（照片/平色图不建议，AI 会劝你）
- 边缘描边（Logo 风格）：`--outline 1`
- 敏感色保护（人像肤色）：`--sensitive 1`
- 一次对比多方案让 AI 选：`--compare-matrix`
- 全部参数以包内 `SKILL.md` 参数表为准；跑图时 AI 的每一步理由都在命令行输出里
